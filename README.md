## Project Lifecycle

```text
IDEA
 ↓
PLANNING
 ↓
PROTOTYPE
 ↓
ACTIVE
 ↓
VALIDATION
 ↓
COMPLETED
 ↓
FOLLOW-UP / RESEARCH / DEPLOYMENT
```

모든 프로젝트가 반드시 같은 순서로 진행될 필요는 없습니다.  
다만 모든 공식 프로젝트는 현재 상태와 다음 목표를 기록합니다.

---

## Official Project Requirements

PAICHAI NEXUS 공식 프로젝트는 최소한 다음 항목을 갖습니다.

- [ ] GitHub Repository
- [ ] README
- [ ] Project Lead
- [ ] Defined Problem
- [ ] Project Members / Roles
- [ ] Current Status
- [ ] Next Milestone
- [ ] Documentation
- [ ] Expected Output

회의에서 나온 아이디어만으로는 공식 프로젝트로 등록하지 않습니다.

```text
Idea
 ↓
Internal Review
 ↓
Project Lead
 ↓
Repository
 ↓
README / Milestone
 ↓
Official Registry
 ↓
Development / Research
 ↓
Validation
 ↓
Result / Handover
```

## Repository Rules

각 프로젝트 저장소에서는 최소한 다음 내용을 확인할 수 있도록 합니다.

1. 해결하려는 문제
2. 현재 상태
3. Project Lead
4. 참여자와 역할
5. 지도·자문 교수 또는 협력자
6. 현재 진행 내용
7. Next Milestone
8. 실행·실험 방법
9. 결과물
10. 인수인계 자료

프로젝트가 보류되거나 종료되더라도 기록을 삭제하지 않습니다.  
후배 학생이나 다음 담당자가 이전 프로젝트의 결과와 시행착오를 이어받을 수 있도록 남기는 것을 원칙으로 합니다.
